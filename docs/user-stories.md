# Kullanıcı hikâyeleri ve kabul koşulları

| Hikâye | Kabul koşulu |
|---|---|
| Dil öğrenen biri olarak bildiğim ve pratik yapacağım dili seçmek istiyorum. | Beş dil arasında 20 farklı yön desteklenir; aynı iki dil reddedilir. |
| Kısa bir tur oynamak istiyorum. | Kolay 4/60, orta 6/45, zor 8/35 çift/saniye ayarına uyar. |
| Yanlışımı anlayıp tekrar denemek istiyorum. | Yanlış −5, doğru +10; eşleşen kart tekrar puanlanmaz; puan negatif olabilir. |
| Tercihlerimin sonraki açılışta hatırlanmasını istiyorum. | Dil, zorluk, tema, renk ve ses yazılıp yeniden yüklenir. |
| Ekran kullanmadan terminalde oynayabilmek istiyorum. | --console ile menü, dil/zorluk seçimi, eşleştirme ve sonuç çalışır; süre Enter beklemeden dolar. |
| Kelimeleri çalışırken alfabetik görmek istiyorum. | Konsolda ikinci sıralama politikası seçilince sütunlar kendi dillerine göre sıralanır; puanlama aynı kalır. |
| Programı değerlendiren öğretmen olarak kolayca derleyebilmek istiyorum. | Temiz checkout üzerinde mvnw clean verify çalışır, README örnek komutları açıklar. |
| Öğrenci olarak tasarımımı açıklayabilmek istiyorum. | UML, Strategy açıklaması ve sözlü anlatım rehberi kaynak kodla aynı sınıfları kullanır. |
